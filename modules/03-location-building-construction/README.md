# Module 03 — Location, Building & Construction (folder)

**Primary lesson (study this first):** [`../03-site-building.md`](../03-site-building.md)

## Covered here (via primary notes)

- Site selection: power, fiber, flood/seismic/weather, adjacency, people/MTTR, expansion, water/heat rejection
- Supporting facilities (NOC, staging, docks, gen yards, grey space)
- Building attributes for HA (load, height, column grid, dual-path layout, fire compartments)

## Self-check (no peeking)

1. White space can look perfect while undersized grey/support space breaks operations.  
2. Dual utility must be **independent upstream**, not two cables on one feed.  
3. Raised floor is **not** a flood-mitigation strategy.
