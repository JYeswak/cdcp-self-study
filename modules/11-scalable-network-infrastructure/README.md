# Module 11 — Scalable Network Infrastructure (folder)

**Primary lesson (study this first):** [`../11-network.md`](../11-network.md)

## Covered here (via primary notes)

- Structured cabling as a 10–15+ year facility asset
- Copper vs multimode/single-mode fibre trade-offs
- TIA-942 topology spaces: entrance, MDA, HDA, EDA, optional ZDA
- Pathways, separation from power, fill ratios, firestopping
- Testing: certification, OLTS, OTDR, polarity, labeling/as-builts
- Physical diversity: dual entry, dual paths, MMR/carriers; monitoring

## Self-check (no peeking)

1. Logical dual uplinks that share one trench are **not** diverse.  
2. Certification/as-builts beat “link light is green.”  
3. Pathways and spare capacity are day-one design, not year-three hope.
