## Covered here (via primary notes)

- Full utility → transformer → gen → ATS/STS → UPS → PDU/busway → rack path
- ATS vs STS; generators and fuel/runtime
- N / N+1 / 2N / 2N+1 and SPOF thinking
- Single-phase vs three-phase; floor PDU vs rack PDU; busbar vs cable
- UPS topologies (VFI/online, etc.), parallel configs, batteries/BESS
- Power quality, sizing (kW/kVA/PF), thermography, HPC density
- Sustainability/PUE, **microgrid** concepts, **IP enclosure ratings**

## Self-check (no peeking)

1. Generators are not instant — UPS covers start/transfer.  
2. N+1 modules behind one shared bus can still be a SPOF.  
3. Dual-corded gear needs true A+B independence, not two plugs on one strip.
