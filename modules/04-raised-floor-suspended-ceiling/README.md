# Module 04 — Raised Floor & Suspended Ceiling (folder)

**Primary lesson (study this first):** [`../04-floor-ceiling.md`](../04-floor-ceiling.md)

## Covered here (via primary notes)

- Raised floor vs slab designs; when modern halls skip raised floor
- Uniform / concentrated / rolling loads
- Grounding, bonding, **SRG (Signal Reference Grid)**
- Ramps, landings, accessibility
- Suspended ceiling as return plenum / pathway trade-offs
- Airflow impact (missing tiles, cable dams, perforated-tile placement)

## Self-check (no peeking)

1. Rolling and concentrated loads often govern equipment moves more than “average” uniform load.  
2. Open/missing tiles dump plenum pressure and create hotspots elsewhere.  
3. SRG/bonding is design work — leave straps intact; do not freestyle grounds.
