## Self-check (no peeking)

1. Mission-critical is defined by **business impact**, not rack kW alone.  
2. Dual PSUs do **not** guarantee dual upstream paths — trace the path.  
3. Availability depends on MTBF **and** MTTR (and redundancy independence).
