# Module 08 — Equipment Racks (folder)

**Primary lesson (study this first):** [`../08-racks.md`](../08-racks.md)

## Covered here (via primary notes)

- 19″ EIA / RU / depth / 600 vs 800 mm cabinets
- Open frame vs cabinet; seismic; airflow doors/perforation
- Rack security (locks, sensors, cage vs cabinet)
- Rack PDUs/strips: A/B feeds, zero-U, metering, phase balance, outlet types
- Blanking panels, cable management, weight and grounding bars

## Self-check (no peeking)

1. “19-inch” is mounting standard, not outer cabinet width.  
2. Blanking panels stop bypass airflow — cheap availability tool.  
3. Both cords on one PDU defeats dual-path design.
