# Module 02 — Data Centre Standards (folder)

**Primary lesson (study this first):** [`../02-standards.md`](../02-standards.md)

## Covered here (via primary notes)

- ANSI/TIA-942 Rated concepts (awareness)
- Uptime Institute Tier I–IV (commercial rating — not the same as TIA)
- ISO/IEC 22237 series (international facilities framework)
- ASHRAE TC 9.9 thermal guidelines (recommended vs allowable)
- Standard vs guideline vs code vs certification; AHJ wins on codes

## Self-check (no peeking)

1. Local electrical/fire **code** enforced by the **AHJ** overrides voluntary standards when they conflict.  
2. “Tier III” and “TIA Rated-3” are **related ideas**, not interchangeable certificates.  
3. ASHRAE envelopes guide inlet temperature/humidity policy — they are not building law by themselves.
