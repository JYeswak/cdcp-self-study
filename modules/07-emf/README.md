# Module 07 — Electro Magnetic Fields (folder)

**Primary lesson (study this first):** [`../07-emf.md`](../07-emf.md)

## Covered here (via primary notes)

- E-field vs B-field vs RF; ELF power-frequency magnetic issues
- Sources: transformers, busbars, UPS, elevators, rail, RF
- Units (µT, mG, V/m); distance fall-off intuition
- Mitigation hierarchy: separation → orientation → routing → bonding → shielding
- (H)EMP / IEMI awareness without overclaiming hardening

## Self-check (no peeking)

1. Prefer **distance** over exotic magnetic shielding for 50/60 Hz B-fields.  
2. Do not put network core against UPS/transformer walls without survey thinking.  
3. Most “EMF packet loss” stories are grounding/termination/thermal until proven otherwise.
