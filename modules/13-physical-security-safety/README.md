# Module 13 — Physical Security & Safety (folder)

**Primary lesson (study this first):** [`../13-security.md`](../13-security.md)

## Covered here (via primary notes)

- Defense-in-depth: perimeter → building → suite → cage/rack
- Zoning, access control factors, anti-passback, visitor management
- Mantraps / interlocks; surveillance/VMS roles
- Security vs **safety** (egress, LOTO awareness, fail-safe locks)
- Insider threat and process failures (tailgating, propped doors)

## Self-check (no peeking)

1. One strong door is not a security program — layers matter.  
2. Grey space (UPS/chillers) is high-value for sabotage/error.  
3. Security cannot defeat free egress required by life safety.
