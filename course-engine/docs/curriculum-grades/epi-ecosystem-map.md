## Track Contract

Each track must have:
1. `tracks/<id>/manifest.toml` with required fields
2. Honesty banner stating "not an EPI credential"
3. Hub link from `web/index.html`
4. Learner page at `web/tracks/<id>.html`
5. No claim that 27/40 (or any score) is a pass mark

## Honesty Rules

- No track may claim EPI/EXIN certification
- No track may use "exam dump" or "recalled question" language
- Study signals are "study-only", never "pass-threshold"
- Each track's `manifest.toml` carries its own honesty and rights rows
