# Browser exam packs (`export-web`)

Generated by:

```bash
# EVERY seed runs the sampler, including 42. There is no implicit fixture.
cargo run -q -p cdcp_cli -- export-web \
  --bank bank/items \
  --seed 42 \
  --out web/data

# Other seeds: same sampler path → mock40_seed{N}.json + keys_seed{N}.json
cargo run -q -p cdcp_cli -- export-web --seed 7 --out web/data
```

## Seed policy (L6-S5)

The short-circuit "seed 42 prefers `goldens/fixtures/mock40_seed42.json` when
present" was **deleted** (bd-golden-sampler-divergence-09q). `export-web`
always calls `cdcp_assemble` unless the caller passes `--fixture`.
[[fact:fact-export-web-implicit-fixture-at-seed-42=no]]

| Seed | Source | Role |
|------|--------|------|
| **42** (default) | `cdcp_assemble` stratified sample (`shuffle_choices=false`) | GradeExact digest pin (`goldens check`). export-web reports `golden_pinned=false`. |
| any other `N` | `cdcp_assemble` stratified sample (`shuffle_choices=false`) | Practice variety only — do not refresh goldens from these packs |
| any seed **with `--fixture <path>`** | explicit replay of a recorded `item_ids` list | opt-in only; reports `golden_pinned=true` |

`crates/cdcp_cli/tests/cli.rs::export_web_seed42_runs_the_sampler_not_the_fixture`
goes RED if the implicit preference is restored.

## Files

| File | Audience | Contents |
|------|----------|----------|
| `mock40_seed{N}.json` | Learner UI | `schema_version`, `exam_id`, `seed`, `bank_hash`, `n_items`, stems + choices **only** (no correct letters) |
| `keys_seed{N}.json` | e2e / harness / post-grade explanations | Correct letters + explanations — **not** the learner exam payload |
| `bank_items_seed{N}.json` | WASM `grade_digest_json` | Full `BankItem` array (entire bank; identical across seeds). Includes `correct` so client-side GradeExact can match goldens; `bank_hash` equals `cdcp bank-hash` |

Mock UI seed selector loads `mock40_seed{seed}.json`. If missing, run `export-web --seed N`.

## Answer-key policy

1. **Learner pack omits correct answers.** UI loads `mock40_seed{N}.json` only for display.
2. **Keys file is for harness + results explanations after grade**, not for the take-exam screen.
3. **Client-side grade still needs keys inside `bank_items_*.json`** (and/or WASM-side bank load). That is inherent to offline GradeExact; do not treat `bank_items` as a “learner-safe” file.

## Determinism

Export uses sorted JSON object keys + stable item ordering (exam order for learner/keys; BTreeMap id order for bank items). Two runs on the same bank+seed (and the same `--fixture` when one is passed) produce identical bytes.

## `coverage.json` — deleted (bd-smvb)

This directory used to ship a `coverage.json` ledger. It had no product consumer
and drifted (item_count 798 vs 804; m15 40 vs 39) with no failure. Deleted
rather than wired: a ledger nobody reads cannot be wrong in a way anyone
notices. The live report is `cdcp_gate verify-coverage` stdout. `--write-json
PATH` remains an optional operator dump and is not a shipped input.
