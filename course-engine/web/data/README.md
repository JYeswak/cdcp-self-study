# Browser exam packs (`export-web`)

Generated by:

```bash
# Golden-pinned seed 42 (default): prefers goldens/fixtures/mock40_seed42.json
cargo run -q -p cdcp_cli -- export-web \
  --bank bank/items \
  --seed 42 \
  --out web/data

# Other seeds: stratified assemble → mock40_seed{N}.json + keys_seed{N}.json
cargo run -q -p cdcp_cli -- export-web --seed 7 --out web/data
```

## Seed policy (L6-S5)

| Seed | Source | Golden-pinned? |
|------|--------|----------------|
| **42** (default) | Prefers `goldens/fixtures/mock40_seed42.json` when present | **Yes** — GradeExact digests / `goldens check` |
| any other `N` | `cdcp_assemble` stratified sample (`shuffle_choices=false`) | **No** — practice variety only |

Only **seed 42** is golden-pinned. Other seeds must not be used to refresh or assert golden digests.

## Files

| File | Audience | Contents |
|------|----------|----------|
| `mock40_seed{N}.json` | Learner UI | `schema_version`, `exam_id`, `seed`, `bank_hash`, `n_items`, stems + choices **only** (no correct letters) |
| `keys_seed{N}.json` | e2e / harness / post-grade explanations | Correct letters + explanations — **not** the learner exam payload |
| `bank_items_seed{N}.json` | WASM `grade_digest_json` | Full `BankItem` array (entire bank; identical across seeds). Includes `correct` so client-side GradeExact can match goldens; `bank_hash` equals `cdcp bank-hash` |

Mock UI seed selector loads `mock40_seed{seed}.json`. If missing, run `export-web --seed N`.

## Answer-key policy

1. **Learner pack omits correct answers.** UI loads `mock40_seed{N}.json` only for display.
2. **Keys file is for harness + results explanations after grade**, not for the take-exam screen.
3. **Client-side grade still needs keys inside `bank_items_*.json`** (and/or WASM-side bank load). That is inherent to offline GradeExact; do not treat `bank_items` as a “learner-safe” file.

## Determinism

Export uses sorted JSON object keys + stable item ordering (exam order for learner/keys; BTreeMap id order for bank items). Two runs on the same bank+seed (+ fixture for 42) produce identical bytes.

## WASM glue

See [`../assets/js/grade_bridge.js`](../assets/js/grade_bridge.js).

```bash
# Preferred (repo root):
./scripts/build_web_wasm.sh

# Or manually:
rustup target add wasm32-unknown-unknown
cargo build -p cdcp_wasm --target wasm32-unknown-unknown --release
mkdir -p web/assets/wasm
cp target/wasm32-unknown-unknown/release/cdcp_wasm.wasm web/assets/wasm/
```
